📌 Important Formulas

Some useful formulas for advanced mathematics.

Quadratic Formula: x = (-b ± √(b² - 4ac)) / 2a
Arithmetic Sequence: aₙ = a + (n - 1)d
Arithmetic Series: Sₙ = n/2 [2a + (n - 1)d]
Gradient: m = (y₂ - y₁) / (x₂ - x₁)
Probability: P(E) = Favourable outcomes / Total outcomes

🧠 Worked Example

Let's solve a quadratic equation.

Solve:

x² - 5x + 6 = 0

Factorise:

(x - 2)(x - 3) = 0

Therefore:

x - 2 = 0    or    x - 3 = 0

x = 2 or x = 3
