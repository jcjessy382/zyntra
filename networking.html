🌐 What Is a Computer Network?

A computer network is a group of interconnected computers and other devices that communicate with each other and can share information and resources.

📡 Types of Computer Networks

🏠

LAN

Local Area Network covers a relatively small geographical area such as a home, school, office or computer laboratory.

🏙️

MAN

Metropolitan Area Network connects networks across a city or large metropolitan area.

🌍

WAN

Wide Area Network covers a large geographical area. The Internet is a major example of an interconnected global network.

📱

PAN

Personal Area Network connects devices around an individual, such as a computer, phone and wireless accessories.

📶

WLAN

Wireless Local Area Network connects devices over a local area using wireless communication.

🔗

Internet

The Internet is a worldwide system of interconnected networks that communicate using standardized protocols.

🔌 Networking Devices

🔀

Switch

A switch connects devices within a network and forwards data to the appropriate device.

🌐

Router

A router connects different networks and forwards packets between them.

📡

Access Point

A wireless access point allows compatible devices to connect to a network wirelessly.

📶

Modem

A modem converts signals as needed to enable communication over certain types of network connections.

🛡️

Firewall

A firewall monitors and controls network traffic according to defined security rules.

📶

Network Interface

A network interface allows a computer or device to connect and communicate over a network.

🔢 IP Address and MAC Address

Devices on a network can use different types of addresses for communication and identification.

IP Address MAC Address
A logical network address used for communication. A hardware address associated with a network interface.
Can change depending on the network or configuration. Normally assigned to the network interface by the manufacturer.
Example: 192.168.1.10 Example: 00:1A:2B:3C:4D:5E

📨 Network Protocols

Network protocols are agreed rules that allow devices and applications to communicate.

🌐

HTTP

A protocol used for communication between web browsers and web servers.

🔒

HTTPS

HTTP communication protected using encryption through TLS.

📦

TCP

A transport protocol that provides reliable, ordered delivery of data.

⚡

UDP

A transport protocol that sends data without TCP's connection and reliability mechanisms.

🧭

IP

Internet Protocol provides addressing and routing for packets between networks.

📧

DNS

The Domain Name System translates domain names into IP addresses and other DNS information.

🧱 TCP/IP Model

The TCP/IP model describes how network communication is organized into layers.

Layer Main Purpose
Application Provides network services used by applications.
Transport Provides end-to-end communication and transport services.
Internet Handles logical addressing and routing.
Network Access Handles communication over the local network connection.

📚 Quick Revision

  • A network connects computers and other devices so they can communicate and share resources.
  • LAN covers a relatively small geographical area.
  • WAN covers a large geographical area.
  • A switch connects devices within a network.
  • A router connects different networks.
  • An IP address is a logical network address.
  • A MAC address identifies a network interface at the link layer.
  • TCP provides reliable and ordered transport.
  • DNS helps translate domain names into IP addresses and other DNS information.
