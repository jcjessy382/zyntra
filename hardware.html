Understand the Machine.

Computer hardware refers to the physical parts of a computer that we can see and touch. Learn how the major components work together to make a computer system function.

💻 What Is Computer Hardware?

Computer hardware is the collection of physical components that make up a computer system. Examples include the keyboard, mouse, monitor, motherboard, processor, memory and storage devices.

🔧 Main Hardware Components

🧠

CPU

The Central Processing Unit is the main processor of a computer. It executes instructions and processes data.

🧩

Motherboard

The motherboard is the main circuit board that connects important computer components.

💾

RAM

Random Access Memory temporarily stores data and programs currently being used.

💽

Storage

Storage devices such as hard disks and SSDs keep data and programs for long-term use.

⌨️

Keyboard

A keyboard is an input device used to enter text, numbers and commands into a computer.

🖱️

Mouse

A mouse is an input device used to point, select, click and interact with objects on the computer screen.

🖥️

Monitor

A monitor is an output device that displays information and images produced by a computer.

🖨️

Printer

A printer is an output device that produces a physical copy of information on paper.

🔊

Speakers

Speakers are output devices that produce sound from a computer.

📥 Input vs Output Devices

Input devices send data or instructions into a computer, while output devices present processed information to the user.

🧠 The CPU

The CPU is often described as the "brain" of the computer because it processes instructions and controls many computer operations.

➕

ALU

The Arithmetic and Logic Unit performs arithmetic calculations and logical operations.

🎛️

Control Unit

The Control Unit coordinates and controls the activities of the computer.

📦

Registers

Registers are very small, fast storage locations inside the CPU used during processing.

💾 Computer Memory

Computer memory stores data and instructions that the processor needs.

⚡

RAM

RAM is temporary memory. Its contents are normally lost when the computer is switched off.

🔒

ROM

ROM is non-volatile memory that stores important instructions that remain available when power is removed.

💽

Secondary Storage

Examples include hard disk drives, SSDs, flash drives and memory cards.

📚 Quick Revision

  • Hardware = physical parts of a computer.
  • CPU = processes instructions and data.
  • Keyboard and mouse = input devices.
  • Monitor and printer = output devices.
  • RAM = temporary working memory.
  • ROM = non-volatile memory.
  • Motherboard = connects major components.
  • SSD and HDD = secondary storage devices.
