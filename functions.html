What is a Function?

A simple way to understand functions

A function is a rule that connects each input to exactly one output.

We often write a function as:

f(x) = 2x + 3

Here, x is the input and f(x) is the output.

Worked Example

Let's evaluate a simple function.

Given:

f(x) = 2x + 3

Find f(4).

Substitute x = 4:

f(4) = 2(4) + 3

f(4) = 8 + 3

Therefore, f(4) = 11

Quick Revision

Key points to remember.

Input

The value placed into a function.

Output

The value produced by the function.

Domain

The set of possible input values.

Range

The set of possible output values.
