🔢 What Is Data Representation?

Data representation is the way information is converted into a form that a computer can store, process and communicate.

Computers use electronic systems that work with two states, commonly represented as 0 and 1.

💾 Bits and Bytes

0️⃣

Bit

A bit is the smallest basic unit of digital information. It can have a value of 0 or 1.

8️⃣

Byte

A byte consists of 8 bits.

📦

Storage Units

Larger units include kilobytes, megabytes, gigabytes and terabytes.

📊 Common Data Units

Unit Relationship
Bit 0 or 1
Byte 8 bits
Kilobyte (KB) Approximately 1,000 bytes in SI usage
Megabyte (MB) Approximately 1,000 KB in SI usage
Gigabyte (GB) Approximately 1,000 MB in SI usage
Terabyte (TB) Approximately 1,000 GB in SI usage

🔢 Number Systems

0️⃣1️⃣

Binary

Binary uses two digits: 0 and 1. Computers commonly use binary representation for digital data.

🔟

Denary

Denary, also called decimal, uses ten digits: 0 through 9.

🔠

Hexadecimal

Hexadecimal uses sixteen symbols: 0–9 and A–F.

🧮 Binary and Denary

Each position in a binary number represents a power of 2.

Example: Convert 1011₂ to denary

1011₂ = (1 × 8) + (0 × 4) + (1 × 2) + (1 × 1)

= 8 + 0 + 2 + 1

= 11₁₀

Example: Convert 13₁₀ to binary

13 = 8 + 4 + 1

Therefore:

13₁₀ = 1101₂

🔤 Character Representation

Computers also need ways to represent text. Character encoding systems assign numerical values to characters so they can be stored and processed.

🔤

ASCII

ASCII is a character encoding standard used to represent common characters using numeric codes.

🌍

Unicode

Unicode provides a much larger character set supporting writing systems and symbols from around the world.

🖼️

Images

Digital images can be represented using pixels, with each pixel storing information such as colour.

📚 Quick Revision

  • A bit is a basic unit of digital information with a value of 0 or 1.
  • 8 bits make 1 byte.
  • Binary uses base 2.
  • Denary uses base 10.
  • Hexadecimal uses base 16.
  • Hexadecimal uses 0–9 and A–F.
  • ASCII and Unicode are character encoding systems.
  • Digital images can be represented using pixels.
