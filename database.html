🗄️ What Is a Database?

A database is an organized collection of related data that can be easily stored, accessed, managed and updated.


Examples include student records, hospital records, bank accounts and library systems.

⚙️ Database Management System

💻

DBMS

A Database Management System is software used to create, manage and control databases.

🗃️

Examples

MySQL, Microsoft Access, Oracle, PostgreSQL and SQL Server.

🔍

Data Retrieval

A DBMS allows users to search and retrieve required information quickly.

🧩 Database Components

📊

Table

A table stores related data in rows and columns.

📝

Record

A record is a complete set of information about one item or person.

🔤

Field

A field is a single category of information in a table.

🔑

Primary Key

A primary key uniquely identifies each record in a table.

🔗 Relational Databases

A relational database stores information in tables that can be connected using relationships.


For example, a school database may have a Students table and a Results table.


A common field such as Student ID can be used to connect the two tables.

🔐 Database Keys

🔑

Primary Key

Uniquely identifies every record in a table.

🔗

Foreign Key

A field used to link one table to another.

🛠️ Database Objects

📊

Tables

Store the actual data.

🔎

Queries

Search, filter or retrieve specific data.

📝

Forms

Provide an easy interface for entering and viewing data.

📄

Reports

Present database information in an organized format.

💻 Introduction to SQL

SQL means Structured Query Language. It is commonly used to communicate with relational databases.


SELECT Name, Class FROM Students WHERE Class = 'Form 4';

This example requests the names and classes of students who are in Form 4.

🚀 Advantages of Databases

⚡ Fast Access

Information can be retrieved quickly.

🔒 Better Security

Access to information can be controlled.

📉 Reduced Duplication

Proper database design can reduce unnecessary duplicate data.

🔄 Easy Updating

Information can be added, changed or deleted.
