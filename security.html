🔐 What Is Computer Security?

Computer security is the protection of computer systems, networks, programs and data from unauthorized access, damage, theft or disruption.


The main goal is to keep information confidential, accurate and available to authorized users.

⚠️ Common Security Threats

🦠

Virus

A malicious program that can attach itself to files and spread when the files are used.

🐴

Trojan Horse

Malicious software that appears to be legitimate or useful.

🎣

Phishing

A trick used to obtain sensitive information by pretending to be a trusted person or service.

🔑

Password Attack

An attempt to gain unauthorized access by guessing or obtaining passwords.

🕷️

Spyware

Software designed to secretly collect information about a user or system.

🚫

Unauthorized Access

Accessing a computer system or information without permission.

🦠 Malware

Type Description
Virus Attaches to files and can spread when infected files are opened.
Worm Can spread across networks without requiring a user to copy it manually.
Trojan Appears legitimate but performs malicious actions.
Spyware Secretly collects information.
Ransomware Can restrict access to files or systems and demand payment from victims.

🛡️ Ways to Protect a Computer

🔒

Strong Passwords

Use long, unique passwords and avoid easily guessed information.

🛡️

Antivirus Software

Helps detect and remove malicious software.

🔥

Firewall

Helps control network traffic entering or leaving a computer or network.

🔄

Software Updates

Updates can fix security weaknesses and improve software protection.

💾

Backups

Keep copies of important information in case the original data is lost.

👤

User Permissions

Give users only the access they need.

🔺 The CIA Triad

🤫

Confidentiality

Information should only be accessible to authorized people.

✅

Integrity

Information should remain accurate and trustworthy.

⚡

Availability

Authorized users should be able to access information when needed.

🧠 Smart Security Rules

  • Never share your passwords with other people.
  • Be careful when opening unexpected links or attachments.
  • Keep your operating system and applications updated.
  • Use security software where appropriate.
  • Back up important files regularly.
  • Lock your computer when you leave it.
  • Avoid entering sensitive information on suspicious websites.

📚 Quick Revision

  • Computer security protects computers, networks and data.
  • Malware is malicious software.
  • A virus can attach itself to files.
  • Phishing attempts to trick people into revealing information.
  • A firewall helps control network traffic.
  • Antivirus software helps detect malware.
  • Backups help protect against data loss.
  • CIA means Confidentiality, Integrity and Availability.
